# 分镜、混音与交付

## 项目记录

建议每个项目保存来源页图/裁切索引、角色库、场景脚本、各版原始音频和请求摘要、独立音轨、实际时间线与成片。目录名按项目习惯决定。每个画格记录来源PDF实际页号与裁切坐标，每个生成版本记录角色映射和参考散列。

分镜是导演判断，不是自动按字数轮播图片：建立空间关系，用人物特写承载对白，用反应镜头表现沉默，用手部和物件交代发现。选取具有叙事作用的雨、门、纸牌等细节。不要裁掉重要表情、手势或对白气泡到令人困惑；保留完整气泡或合理避开，不让残片干扰画面。对低清扫描避免过度放大。

## 声音后期

Seed联合场景输出可能自带BGM和音效。先检查现有内容再补轨，避免重复脚步、门声和纸牌声。独立素材可以由Seed纯音频生成，也可使用用户授权的来源。角色试音和实际场景音轨分开管理。

混音清单记录每条素材的实际路径、来源请求、起止、增益、淡入淡出、对齐动作。动作的声响峰值不一定在文件起点，不能只把文件起点贴到画面动作上。实际试听/波形定位后放置。对白驱动BGM降低约4–8dB可作为起点；关键怒喝前收弱，句后保留自然停顿。响度目标约-17至-16 LUFS、真峰值不高于-1.5dBTP可作为起点，根据目标平台和实际听感调整，不为达标抹掉表演动态。

输出混音WAV，检查峰值及结尾有无截字。不要为了整数30秒截掉最后音节。若实际时长变化，更新画格、字幕与下一段全局偏移。拼接背景声可淡接；对白不得重叠或因淡出丢字。

## 可复用渲染脚本

`render_scene.py`只负责已设计的时间线，不替代阅读漫画、选角或混音。输入WAV，渲染时长取真实WAV时长并最多补到下一帧，不固定30秒。需要Python、Pillow以及系统FFmpeg或imageio-ffmpeg。字体由项目提供支持该语言的字体路径，不把字体文件打包进技能。

时间线JSON中的文件路径相对JSON文件目录。`rect`为归一化`[x,y,width,height]`。`contain`保持原图完整，zoom默认0.98→1；`cover`按焦点裁切填满，zoom默认1→1.04。字幕使用Seed毫秒时间戳；先按脚本给每句附上真实角色标签，不能硬编码特定漫画的台词识别说话人。

以下是4秒原创测试片段的结构示例；实际项目用真实音频时长和裁切图替换：

```json
{
  "size": [1920,1080], "fps": 24,
  "audio": "audio/mix.wav", "font": "fonts/chinese.ttf",
  "images": {"wide":"panels/wide.png", "face":"panels/face.png"},
  "shots": [
    {"start":0,"end":2,"panels":[{"image":"wide","rect":[0.04,0.05,0.92,0.75],"fit":"contain"}]},
    {"start":2,"end":4,"panels":[{"image":"face","rect":[0.25,0.05,0.5,0.75],"fit":"cover","focus":[0.5,0.3]}]}
  ],
  "subtitles": [{"start_time":500,"end_time":1800,"speaker":"巡夜人","text":"等等。",
    "words":[{"start_time":500,"end_time":900,"text":"等"},{"start_time":900,"end_time":1800,"text":"等。"}]}]
}
```

```text
python <skill>/scripts/render_scene.py timeline.json --output preview.png --preview-at 2.5
python <skill>/scripts/render_scene.py timeline.json --output scene-v1.mp4
```

先预览关键画格、字幕与情绪转折，再编码。多格布局在一个shot的panels中添加多个区域；区域变化决定注意力，少量轻微推近即可，动作突变时才用短促推镜。复杂视差、天气或字幕样式由项目脚本实现；不要默认让漫画人物动嘴或重新生成人物。

## 拼接与验证

所有片段统一分辨率、像素格式、帧率和音频采样率。根据各段实际时长累计全局偏移，字幕也要累加，不假设每段恰好30秒。可用FFmpeg concat，完成后检查总时长和接缝；必要时重编码，不能仅改文件后缀。

- 完整解码：`ffmpeg -v error -i final.mp4 -f null -`。
- 抽帧检查：开场、角色切换、情绪高潮、字幕长句、结尾和拼接点；关注裁切、可读性、空白和错误角色标签。
- 试听/独立识别状态单独记录，不能从静音解码、返回字幕或峰值统计推断咬字和情绪已通过。
- 简洁交付：可播放视频、连播版（如需要）、关键短试听（针对反馈）、字幕与Prompt链接。只陈述做过的验证。旧版保留，获得明确偏好后再确定采用版本。
