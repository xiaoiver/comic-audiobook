# 角色、表演与声音叙事

## 初次选角

文字设定覆盖创作年龄、性别呈现、语言/口音、音域、音质、语速和性格。可从漫画选择角色形象或表情作为初次试音参考图；图片不保证理想音色，仍需听感选择。图片和音频的模式组合见seed-api.md。

独立试音示例（原创台词）：

```text
生成约8–12秒单人中文试音，无音乐、音效和环境声。
巡夜人（成年男性，普通话，低沉但吐字清晰，略沙哑，沉着且警觉）说道：“先别开门。告诉我，你听见了什么。慢慢说，我在听。”
只读台词，不朗读说明。
```

角色库记录`id`、`display_name`、`reference`、真实`sha256`、`casting`、`review_status`。状态区分已生成、技术检查、已试听、用户认可；不要自动将前三者视为用户认可。角色身份与每次请求的音频编号分开保存。

## 正式Prompt示例

以下仅示范写法，不带入新漫画。references数组必须实际按顺序包含两位角色录音。

```text
生成约25秒有声漫画，自然展开。巡夜人使用@音频1，目击者使用@音频2。参考固定声音身份，表演随情节变化。仅朗读引号内台词。

雨滴清晰敲打薄铁屋檐，下方有细小溅水声。低音弦乐缓慢进入，阴冷、纯器乐，无吟唱。
巡夜人（@音频1，低声但警觉）说道：“刚才是谁从这里过去？”

湿靴在石阶上停住，衣料摩擦，远处门板短促碰响。音乐稍稍收紧。
目击者（@音频2，受惊，急切解释，咬字清楚）说道：“我没看清！他跑得太快了！”

巡夜人向前一步，脚步近而重。音乐迅速收弱，留下短暂安静。
巡夜人（@音频1，耐心耗尽，突然提高声量，胸腔发力，短促怒喝，整句发音完整）说道：“往哪边跑了？！”

问句后保留一口气的停顿，低弦乐回落，雨声延续。音效与音乐清楚可辨，但不能盖住台词。
```

若视频确有锁定节点，可在“说道：”后加`[2.7s:5.7s]`；给足完整说话和换气时间，用输出校验偏差。不要让密集音效时刻、窄对白窗口、逐字拖长与固定总时长互相挤压。

## 定向修复

| 问题 | 优先检查/调整 |
| --- | --- |
| 所有人像同一旁白 | 实际参考是否上传；顺序与标记是否一致；独立试音是否分明；必要时分组生成 |
| 标记或说明词混入 | 引号只包实际台词；设定放括号；去掉说明里的引用词，不只追加“不要读说明” |
| 情绪一直平静 | 描述动作引发的压抑→迫切→不耐→爆发；明确大声怒喝，减少互相抵触的克制、轻声要求 |
| 怒吼错读、吞字、重复 | 减少音节级操纵、拖长和粗粝效果；放宽时间；让力度与重音表达愤怒，保持完整发音 |
| 音效几乎听不见 | 检查是否反复要求极轻；明确关键音效可辨；补充独立音轨并对齐停顿 |
| 语音为画面而过快 | 延长镜头或精简台词；不默认变速，不剪掉未说完的字 |
| BGM遮挡 | 对白期间降低配乐，关键问句前收弱，保留动作瞬态和句后停顿 |

不能仅以关键词或声学统计宣布修复。保存版本、短试听和实际验证状态。
